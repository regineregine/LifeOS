# LifeOS – Your Personal Life Manager

LifeOS is a personal life management dashboard designed to help organize everyday activities, track goals, manage finances, and stay productive.

## Features

- Task Management
- Goals Tracking
- Finance Management
- Calendar and Events
- AI Assistant
- Automatic Light and Dark Mode

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Project Status

Currently in development.
